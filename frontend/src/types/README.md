# Frontend TypeScript Types

This directory defines TypeScript interfaces and type definitions mirroring the backend API contracts:
- `Observation`: Archive observation metadata, spatial footprints, and spectral band information.
- `Comparison`: Comparison job parameters, alignment status, and preview URLs.
- `Candidate`: Photometric measurements, morphology metrics, ML ranking scores, and provenance records.
- `ApiError`: Typed API error responses matching RFC 7807 problem details.
