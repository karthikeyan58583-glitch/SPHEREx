# SPHEREx TimeLens — Frontend

> Interactive web application for celestial target search, multi-epoch observation discovery, and side-by-side astronomical comparison.

---

## 1. Responsibilities & Boundaries

The frontend provides the user interface for SPHEREx TimeLens. Its core duties are:
- Providing an intuitive celestial coordinate search and target entry interface.
- Displaying timelines and coverage summaries of available SPHEREx observations.
- Presenting side-by-side multi-epoch previews and aligned difference image overlays.
- Inspecting candidate temporal changes with provenance details and quantified uncertainty.

### Strict Scientific Boundary
**The frontend does not duplicate scientific processing implemented by the backend.**<br />
The frontend will not parse raw multi-megabyte FITS files, perform WCS reprojection or coordinate calculations, or compute mathematical difference matrices. It consumes pre-rendered display previews (WebP/PNG) and typed JSON metadata generated by the FastAPI backend.

## 3. Directory Layout

* `public/`: Static web assets, branding, and icons.
* `src/app/`: Application shell, routing, layout wrappers, and global provider state.
* `src/components/`: Reusable, generic UI components (buttons, modals, sliders, loaders).
* `src/features/`: Domain-specific application feature modules:
  * `features/sky-search/`: RA/Dec input, cone search parameters, and coordinate validation.
  * `features/observations/`: Observation table, epoch timeline, and band selection.
  * `features/comparison/`: Synchronized dual-epoch side-by-side viewer and difference view.
  * `features/candidates/`: Candidate change list, score sorting, and detail inspection modals.
* `src/lib/`: API client utilities, HTTP error handlers, and formatting helpers.
* `src/types/`: TypeScript type definitions matching the backend Pydantic API contract.
* `tests/`: Component and UI unit tests (planned using Vitest / React Testing Library).
