# ML Exploratory Notebooks (`ml/notebooks/`)

This directory is reserved for Jupyter notebooks used in exploratory analysis and model experimentation:
- Feature distribution analysis and anomaly visualization.
- Threshold tuning and ROC curve evaluation on validation sets.
- Comparison of classical ML models against rule-based heuristic baselines.

### Policy Note
* Notebook outputs containing large embedded astronomical images must be cleared before committing.
* Checkpoints (`.ipynb_checkpoints/`) are ignored via `.gitignore`.
