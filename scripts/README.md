# Utility & Automation Scripts (`scripts/`)

This directory contains utility scripts for administrative and maintenance tasks:
- `verify_archive.py`: Probing NASA/IPAC IRSA SIAv2 availability and listing public SPHEREx collections.
- `cache_cleanup.py`: Manual or scheduled purging of local cache files exceeding size/time limits.
- `generate_test_fixtures.py`: Generating deterministic synthetic FITS test files for the automated test suite.
