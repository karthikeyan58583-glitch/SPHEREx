# Processed Data Storage (`data/processed/`)

This directory temporarily stores intermediate and processed scientific data products generated by the processing pipeline:
- Reprojected target FITS cutouts matched to reference WCS grids.
- Normalized difference arrays and propagated error/uncertainty maps.
- Pre-rendered display preview images (WebP/PNG).

### Rules & Exclusions
* **Git Exclusion**: All generated data files (except this `README.md`) are excluded from version control via `.gitignore`.
* **Reproducibility**: Any file generated in this directory must be reproducible from the raw archive observations and recorded processing parameters.
