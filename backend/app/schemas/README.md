# Backend Pydantic Schemas

This directory contains strongly-typed Pydantic request and response models:
- `health.py`: Health response models.
- `observations.py`: Observation search query parameters and observation metadata models.
- `comparisons.py`: Differencing parameters and comparison result models.
- `candidates.py`: Candidate photometry, morphology, ML ranking, and provenance models.
- `errors.py`: Standardized error envelope models.
